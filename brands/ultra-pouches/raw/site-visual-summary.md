**Buy box detail:** Non-standard purchase flow. No one-time vs. subscription toggle visible. The model appears subscription-first — the primary CTA reads "ADD 3 MORE CANS" with "REFILLS MONTHLY | CANCEL ANYTIME" copy. Users select quantities per individual flavor using steppers (all default to 0), building a custom bundle. Sleep Pouches row is embedded within the flavor selector, functioning as an in-buy-box upsell. No pre-selected quantity or pre-selected flavor on page load — all steppers start at 0, requiring active user configuration before add-to-cart is enabled.

**Price display:** No price visible in the buy box across all 3 PDP folds. Pricing is not revealed until items are added and cart is opened. Compare-at pricing ($48 struck through) and active subscription price ($31.20) only become visible in the cart drawer. No per-unit, per-pouch, or per-day cost shown on PDP.

**CTA behavior:** "GET 45% OFF" floating pill persists across all 3 PDP folds. Primary buy box CTA "ADD 3 MORE CANS" is positioned in fold 2, below the fold on initial page load. Not sticky on desktop as shown. On mobile this CTA would likely require scrolling to reach.

**Trust signals:** Star rating (★★★★★) and "52,032 HAPPY CUSTOMERS" are visible in fold 1 directly above the product title — well-positioned relative to the buy box. No guarantee copy or return policy visible in or near the buy box across folds 1-3. No shipping promise visible in buy box area; shipping info is in the "Shipping & Subscriptions" tab in fold 3.

**Upsell mechanics:** Sleep Pouches row embedded within the flavor selector in fold 2 functions as a cross-sell. The "ADD 3 MORE CANS" CTA copy implies the default subscription unit is 3 cans, nudging toward higher order quantity.

**Layout anomalies:** No price displayed on PDP is a significant departure from standard ecommerce pattern. All flavor steppers default to 0, requiring multi-step user configuration before purchase is possible. Batch urgency calendar (97% reserved, sold out dates) creates scarcity framing but appears below fold 1.
