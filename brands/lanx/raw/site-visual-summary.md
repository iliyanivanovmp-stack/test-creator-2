AXIS collection is the sole hero message; no secondary offer or promo beyond the top bar's "10% off first order."

## PDP

**Fold 1:** Two-column layout — left: large product image gallery (2 images side by side: single boot profile view, pair of boots front-facing with tongue tags showing "365"/"LANX" branding). Right (buy box): breadcrumb (Home / All Men's Footwear), product name "RIBCHESTER," price "€219.95," star rating with review count top-right (4.5 stars, 228 reviews), loyalty-credits line ("Earn €21.99 loyalty credits — learn more"), truncated description with "Read More" link, two icon badges (Water-resistant, Vibram Sole), "COLOUR · CONKER DISTRESSED" with 6 color swatches, "SELECT SIZE" grid (18 size options, 6/6.5/7.../14), "SIZING ADVICE" link (pencil icon) positioned top-right of the size grid — not inline with sizes, "True to Size — Order your usual size" note below the grid, full-width "SELECT SIZE" button (primary CTA, currently disabled/placeholder state), secondary "Buy with Shop" button below it.
**Fold 2:** Lifestyle photography continues — close-up of boots on wooden steps (left) and full-body shot of a man wearing the boots outdoors in a forest/field setting (right). Buy box (right column, sticky/persistent across scroll) shows the same content as fold 1: name, price, rating, description, badges, color swatches, size grid, "SELECT SIZE" CTA, "Buy with Shop" button, plus a checklist below: "Need help? – chat with us," "We recommend shoe care for this product – learn more," "Free UK shipping – learn more," "Free UK returns & exchanges – learn more" (all with checkmark icons).
**Fold 3:** More lifestyle imagery — close-up of boot tread walking on a trail, and a boot resting on a tree stump. Buy box column remains identical/sticky (same content as fold 2). A floating "GET 10% OFF" banner appears bottom-right of the buy box area.
**Buy box detail:** Single purchase option only — no subscription, bundle, or multi-tier buy box observed. One product, one price, "Buy with Shop" as the only secondary payment option shown.
**Price display:** Single price shown (€219.95). No compare-at/strikethrough pricing, no per-unit/per-day cost, no visible installment/BNPL messaging in the buy box itself (BNPL was seen only in a Google ad, not on this PDP).
**CTA behavior:** The buy box (including the "SELECT SIZE" CTA) appears to be sticky/persistent in the right column across all three folds captured — same buy box content visible at each scroll depth alongside changing lifestyle imagery on the left.
**Trust signals:** Star rating + review count (4.5 stars, 228 reviews) sits top-right of the buy box, above the description. Free UK shipping and free UK returns/exchanges are listed as checklist items below the CTA buttons (fold 2 onward), not near the size selector or CTA itself.
**Upsell mechanics:** None visible on the PDP itself in folds 1-3 (upsell/cross-sell appears later, in the cart drawer — see below).
**Layout anomalies:** "SIZING ADVICE" link is a small pencil-icon text link positioned far right of the size-grid header row, easy to miss relative to its importance (matches the sizing-confusion friction flagged in third-party research).
